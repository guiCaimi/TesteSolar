Teste de modelo

Protótipo para testar três coisas: variáveis com nome em vez de endereço de célula, override em qualquer campo calculado, e um rascunho de contas livres.

Entradas

Digite à vontade. Tudo recalcula na hora.

Calculados

Pode digitar por cima de qualquer um. O campo fica amarelo e o ↺ devolve a fórmula.

Rascunho

Uma conta por linha. Use nome = conta para reaproveitar o resultado nas linhas de baixo. Clique no nome de qualquer campo acima para inserir a variável aqui. Separe argumentos com ; e use vírgula decimal, igual na planilha.

Funções disponíveis

Para criar uma função nova, adicione uma linha em modelo.js.
